Fonts embedded in the PDF invoices and reports.

- Archivo (Omnibus-Type), SIL Open Font License 1.1 — https://fonts.google.com/specimen/Archivo
- JetBrains Mono (JetBrains), SIL Open Font License 1.1 — https://www.jetbrains.com/lp/mono/

Static TTF builds taken from the @expo-google-fonts packages. Archivo is used for all
text because it includes the Indian rupee sign (₹).
